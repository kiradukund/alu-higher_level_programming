# JavaScript - Web jQuery

This project covers DOM manipulation and AJAX requests using jQuery, including:

- Selecting HTML elements with jQuery selectors
- Modifying element styles and classes
- Updating element content
- Binding click events
- Making GET requests to external APIs and rendering the results

## Requirements

- All files end with a new line
- Code is semistandard compliant (`semistandard --global $`)
- jQuery 3.x is used for all jQuery-based tasks
- `var` is not used anywhere
- No page reloads are required for any DOM update

## Tasks

| File | Description |
| --- | --- |
| `0-script.js` | Turns `<header>` red using `document.querySelector` (no jQuery) |
| `1-script.js` | Turns `<header>` red using jQuery |
| `2-script.js` | Turns `<header>` red on click of `DIV#red_header` |
| `3-script.js` | Adds class `red` to `<header>` on click of `DIV#red_header` |
| `4-script.js` | Toggles `<header>` class between `red` and `green` on click |
| `5-script.js` | Appends a new `<li>Item</li>` to `UL.my_list` on click |
| `6-script.js` | Updates `<header>` text on click of `DIV#update_header` |
| `7-script.js` | Fetches a Star Wars character's name and displays it in `DIV#character` |
| `8-script.js` | Fetches all Star Wars movie titles and lists them in `UL#list_movies` |
| `9-script.js` | Fetches a translated greeting and displays it in `DIV#hello` |
