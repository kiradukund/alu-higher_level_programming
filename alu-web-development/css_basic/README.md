# CSS Basic

A project introducing CSS fundamentals including selectors, specificity, the box model, and Flexbox layout.

## Files

- `index.html` - Main webpage
- `tweets.html` - Tweets page
- `base.css` - Base stylesheet
- `styles.css` - Custom styles with Flexbox layout

## Concepts Covered

- What is CSS and how to add style to HTML elements
- CSS selectors and specificity
- The CSS Box Model
- Flexbox layout
- Responsive web design
